# Sound Files for Hakinga

This directory contains sound effects for the typing experience.

## Directory Structure

```
sounds/
├── mechanical/     # Mechanical keyboard sounds
│   ├── key-down.mp3
│   ├── key-up.mp3
│   ├── space.mp3
│   └── enter.mp3
├── soft/          # Soft/membrane keyboard sounds
│   ├── key-down.mp3
│   ├── key-up.mp3
│   ├── space.mp3
│   └── enter.mp3
├── typewriter/    # Classic typewriter sounds
│   ├── key-down.mp3
│   ├── key-up.mp3
│   ├── space.mp3
│   └── enter.mp3
├── feedback/      # Feedback sounds
│   ├── error.mp3
│   ├── combo-milestone.mp3
│   ├── combo-break.mp3
│   ├── perfect.mp3
│   ├── complete.mp3
│   └── new-record.mp3
└── progression/   # Progression system sounds
    ├── xp-gain.mp3
    ├── level-up.mp3
    ├── achievement.mp3
    └── rank-up.mp3
```

## Sound Requirements

### Keyboard Sounds
- **key-down.mp3**: Short click sound (50-100ms)
- **key-up.mp3**: Soft release sound (30-80ms)
- **space.mp3**: Slightly deeper/longer click
- **enter.mp3**: Satisfying confirmation sound

### Feedback Sounds
- **error.mp3**: Subtle error indication (not jarring)
- **combo-milestone.mp3**: Exciting milestone sound
- **combo-break.mp3**: Brief disappointing sound
- **perfect.mp3**: Celebratory chime
- **complete.mp3**: Session complete fanfare
- **new-record.mp3**: Special achievement sound

### Progression Sounds
- **xp-gain.mp3**: Quick point gain sound
- **level-up.mp3**: Triumphant level up fanfare
- **achievement.mp3**: Achievement unlock chime
- **rank-up.mp3**: Rank promotion sound
